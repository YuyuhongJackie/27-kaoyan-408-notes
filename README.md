# 27 考研 408 专业课笔记

> 我是一个准备考研计算机大类的大三学生。这个仓库用来记录我在王道 408 网课中的一些笔记和心得，同时记录我在备考这一年里努力的点点滴滴。无论你是谁、因为什么原因点进这个仓库，我希望这些笔记能对你有一些帮助。

## 仓库定位

这里不是教材搬运，也不是逐字稿，而是我在看课、做题和复盘过程中整理出的个人学习记录。

每份笔记尽量包含：

- 完整课件页，便于快速定位和回忆课堂内容
- 精简后的概念解释和知识框架
- 408 常见考法与易错点
- 自测问题
- 必要时补充教材、习题中的辨析

目前从数据结构开始整理，后续会按照复习进度逐章更新。

## 学习方式

我的主线是：

1. 按课程顺序观看王道 408 网课。
2. 记录每节真正会影响做题的概念、方法和易错点。
3. 用课件截图辅助定位知识，用文字完成归纳。
4. 学完一节后做对应习题，把错题和新的理解继续补回笔记。

笔记会持续修改。如果后来的复习发现前面的表述不够准确，我会直接更新原笔记，而不是另建一份重复内容。
